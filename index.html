              2. Binary Exploit Mitigations (Checksec)
            

            

              
NX (No-Execute / DEP):Stack dan heap tidak dapat dieksekusi sebagai shellcode

              
Stack Canary:Nilai acak sebelum $RBP untuk mendeteksi buffer overflow

              
PIE (Position Independent):Base address di-randomize (ASLR) saat runtime

              
RELRO (Full/Partial):GOT (Global Offset Table) dijadikan read-only
