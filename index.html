📚 CTF & Cybersecurity Quick References

            
Daftar opcode x86/x64, magic bytes, SQL injection payloads, dan filter Wireshark.

          

          
        

        

          
1. File Magic Signatures

          
PNG: 89 50 4E 47 0D 0A 1A 0A | JPG: FF D8 FF | GIF: 47 49 46 38

          
ZIP: 50 4B 03 04 | ELF: 7F 45 4C 46 | PE EXE: 4D 5A | PDF: 25 50 44 46

          

          
2. Linux ELF Mitigations (Checksec)

          
NX (No-Execute): Stack non-executable | Canary: Buffer overflow cookie

          
PIE (Position Independent Executable): Randomize code base | RELRO: Read-Only Relocations

          

          
3. Common Encoding Indicators

          
Base64: Charset [A-Za-z0-9+/=], length % 4 == 0

          
Hex: Charset [0-9a-fA-F], length % 2 == 0
